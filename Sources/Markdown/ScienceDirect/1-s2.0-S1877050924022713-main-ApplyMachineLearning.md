1.1. Background and motivation
Weather prediction is very important nowadays, not only in terms of information for people to help with planning.
Predicting the weather forecast is also very important for the economy and agriculture. Monitoring and predicting
weather is used in areas such as agro-culture, controlling the state of air pollution, predicting road conditions to
improve road safety, predicting the spread of natural fires, predicting natural disasters, applying renewable energy
sources, and many others. Accurate prediction of weather conditions is critical to the proper functioning of many
organizations. The U.S. Environmental Information Centers estimated the amount of damage resulting from weather
offer
in 2015 at $7.9 billion. On the other hand, solar forecasting capabilities a chance to save $455 million by 2040
in the use of renewable energy sources [1].

2. Machine learning methods
The problem of weather forecasting can be described using the regression method. It involves statistically model-
ing the response of unknown function values based on known values of independent variables. In weather prediction,
known values of atmospheric measurements can be taken as independent variables and predicted values can be esti-
mated using regression. Classification methods can also be useful for detecting and predicting weather phenomena. In
this article, the following machine learning regression methods will be used for weather forecasting [8] [9] [10]:
• SVR - is a regression method that uses a support vector machine to create predictions. It is based on the creation
of a hyperplane aimed at separating observations from the training set as accurately as possible. The determined
hyperplane equation is then used to classify and calculate regressions for scientific data. The calculation of
the hyperplane equation boils down to the optimization problem of maximizing the distance of the hyperplane
from the points belonging to each class. In addition to carrying out linear regression, SVR can create nonlinear
regressions by applying a “kernel trick,” implicitly mapping the input data domain to a multidimensional space
different
with characteristics.
• Logistic Regression - is a statistical model that predicts the occurrence of an event based on the calculation of a
logit function from a linear combination of independent variables.
• SGD - is a method for training machine learning models through iterative optimization of the objective function.
The application of SGD has obtained good and natural language processing. Under this algorithm, the starting
point selected by the user is subjected to iterative optimization by selecting the direction of the largest decrease
efficient
in the error function. In this way, the solution space is searched in a very way. Unfortunately, ensuring
a global minimum is not always guaranteed.
• KNN - is a simple model that can be used for both regression and classification. It involves selecting k nearest
neighbors from a training set to determine the value for a new observation. After selecting the most similar
observations from the training set, the value of the objective function is averaged.
•
Gaussian regression - is a non-parametric form of the Bayesian method for making predictions. Instead of
calculating the distribution of function parameters, this method can be used to calculate the distribution of the
objective function.
•
PLS - Partial least squares regression- is an algorithm that uses the decomposition of data due to principal
component analysis (PCA) to use the least squares method in the next regression.
•
Decision Tree-is a tree-structured model that aims to predict the value of a goal function based on a subset of
observation attribute values. Decision trees are built based on recursive partitioning of training data due to the

attribute optimizing measure of tree fit (Gini, information gain). Due to the measures used and methods
of building the tree, ID, C4.5, C5.0 and CART algorithms are distinguished.

3.1. Research methodology
The study used the ERA5 meteorological dataset collected by the European Center for Medium-Range Weather
Forecasts (ECMWF) containing hourly data on atmospheric, land, and oceanic variables. For the study, the data was
limited to values describing wind speed, temperature, solar radiation, pressure, precipitation, evaporation, and changes
in watercourse levels.
Although ERA5 contains information dating back to 1940 and covering the entire earth with a 30-km resolution
grid, for the study it was limited to a single location from the time interval 2003 - 2023 and contains only observations
from a single month - January. The dataset used is a reanalysis dataset - it is based on historical data augmented with
advanced modeling methods and data assimilation algorithms. As a comparison of ML algorithms, the following work
uses linear regression algorithm, random forest, decision tree, PLS regression, Gaussian process regression, k nearest
neighbors, SGD regression, and support vector regression. In addition, in an attempt to obtain the best possible results,
the optimization of hyperparameters was carried out using an exhaustive search of the space of available parameters.
To speed up this process, the quality of hyperparameter evaluation is increased as the algorithm runs and better results
are found.
3.2. Data set
The data used in this paper was downloaded from the open source Copernicus Climate Change Service. This site
provides a publicly accessible API through which, any user is able to send a request for the range of data they are
interested in. With this API, it is possible to specify the time frame, geographic range and types of variables. Selected
variables:
•
Vertical and horizontal components of wind speed (u10, v10);
• Temperature 2 meters above ground level (t2m);
•
Changes in watercourse levels (ro);
• Solar radiation (ssr);
•
Thermal radiation (str);
• Pressure (sp);
•
Total evaporation (e);
•
Precipitation (tp).
The data consists of the 9 previously mentioned parameters and 12,648 hourly observations collected from a 20-
month interval. All data are from January and were taken from the 20-year range 2003 - 2023. A location in Poland
was chosen as the location.

3.4. Construction of references
To further approximate the behavior of the various models, summaries of real-time runs and those generated by
machine learning algorithms were created. While the metrics presented give a preliminary understanding of the degree
of fit of the models and their accuracy, graphical analysis is key to understanding which phenomena are predicted
well and which pose problems. The waveforms presented here show weekly waveforms consisting of seven 24-hour
forecasts.
One of the best-evaluated algorithms was support vector regression, a summary of the time series for the SVR
model is shown in Figure 5. In this case, we see good behavior against cyclic waveforms such as solar radiation
and evaporation. In terms of thermal radiation, a good representation of the mean value of the time series is evident,
but a problem with matching individual spikes in values. The sudden jump in precipitation values was completely
ignored in the forecast and indicates problems in predicting sudden events with large amplitudes. Both wind speed
and temperature values were faithfully reproduced by the model created, and the following graphs show how the lines
of the predicted values follow the predicted values. In the case of atmospheric pressure, after a sudden drop, the model
was able to adjust again to the measured data and continue to follow the created trend.
