# WeatherNext Graph deprecation note

- WeatherNext Graph (GraphCast) docs on developers.google.com/weathernext/guides/models-wn-graph mark the model as deprecated as of 2026-07-29; real-time GraphCast forecasts stop and users are pointed to WeatherNext 3.
- Operational data access docs (developers.google.com/weathernext/guides/access-forecast) updated 2026-09-03 describe allowlisted access to WeatherNext 3 datasets; GraphCast/WeatherNext 1 retained for historical benchmarking only.
